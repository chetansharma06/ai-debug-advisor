# Hint Ladder

| Level | Description | Fix leakage |
|---|---|---|
| 1 | Gentlest possible nudge | None |
| 2 | Indirect pattern hint | None |
| 3 | Direct hint with small fragment | Minimal |
| 4 | Strong hint, corrected pattern | High |
| 5 | Full corrected code | Complete |

Guardrail: `LeakDetector` blocks leakage in levels 1–4.
